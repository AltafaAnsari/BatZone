🦇 BatZone — Batman Collectible Store
Enter Gotham. Discover exclusive Batman cards crafted for true fans of the Dark Knight.

🌃 About The Project
Batzon is a full-stack web application inspired by the world of Batman.
Users can explore a collection of unique Batman-themed cards, view details, add favorites to their cart, and purchase directly through an immersive dark-themed interface.

Designed with a cinematic Gotham aesthetic and built using modern full-stack technologies.

✨ Features

🃏 Browse Batman collectible cards
🛒 Add / Remove cards from cart
💳 Buy individual cards or purchase all at once
👤 User authentication using JWT
🔒 Protected routes and secure sessions
📦 Dynamic cart and total calculation
🎨 Responsive dark UI inspired by Gotham City
⚡ Full-stack architecture with database integration
